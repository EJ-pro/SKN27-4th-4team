# 기술스택

## Frontend

| 구분 | 기술 |
|---|---|
| UI 프레임워크 | React 18 |
| 빌드 도구 | Vite 5 |
| 라우팅 | react-router-dom |
| 아이콘 | lucide-react |
| Markdown 렌더링 | react-markdown |
| 스타일링 | Inline style, CSS |

### 주요 프론트엔드 페이지

- `/`: 홈, 서비스 소개, 운동 추천 섹션
- `/exercise`: 운동 백과, 검색/필터/페이지네이션/상세 모달
- `/routine`: 주간 루틴 생성 및 저장
- `/consult`: AI 운동 상담
- `/login`: 로그인 화면

## Backend

| 구분 | 기술 |
|---|---|
| 언어 | Python |
| 웹 프레임워크 | Django 4.2 |
| API 방식 | Django View + JsonResponse + StreamingHttpResponse |
| DB 연동 | Django ORM, raw SQL 일부 |
| 챗봇 | LangChain, LangGraph, OpenAI |
| 임베딩 | OpenAI Embeddings |
| 벡터 검색 | pgvector |

### 주요 API

| API | 역할 |
|---|---|
| `GET /api/exercises/` | 운동 목록 경량 조회 |
| `GET /api/exercises/?full=1` | 운동 전체 상세 목록 조회 |
| `GET /api/exercises/featured/?limit=8` | 홈 추천 운동 조회 |
| `GET /api/exercises/<id>/` | 운동 상세 조회 |
| `GET/POST /api/sessions/` | 상담 세션 조회/생성 |
| `PATCH/DELETE /api/sessions/<id>/` | 상담 세션 수정/삭제 |
| `GET/POST /api/sessions/<id>/messages/` | 상담 메시지 조회/전송 |
| `GET/POST /api/routines/` | 주간 루틴 조회/저장 |

## AI/RAG 구성

| 구분 | 내용 |
|---|---|
| LLM | OpenAI ChatOpenAI |
| 분류 모델 | 운동 질문 유형 분류용 ChatOpenAI |
| 임베딩 모델 | text-embedding-3-small |
| 검색 방식 | vector_search, keyword_search |
| 질문 유형 | specific, general, injury, out_of_scope |
| Rerank | 선택 기능, `CHATBOT_ENABLE_RERANK=True`일 때 CrossEncoder 사용 |

## 배포 시 주의 기술 요소

- 프론트 Docker 이미지에는 `dist`, `node_modules`가 중복 복사되지 않도록 `.dockerignore`가 필요합니다.
- GIF/영상은 이미지에 포함하면 용량이 커지므로 CDN, S3, 별도 static server, volume 분리를 고려해야 합니다.
- `sentence-transformers`는 PyTorch, CUDA 관련 패키지를 끌고 와 backend 이미지가 커질 수 있으므로 기본 배포 이미지에서는 optional dependency로 분리하는 것이 좋습니다.
