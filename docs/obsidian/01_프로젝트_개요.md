# 프로젝트 개요

## 목적 및 배경

HELBOTIN은 사용자가 자신의 운동 목적, 운동 가능 요일, 통증 부위, 운동 시간, 운동 수준을 바탕으로 운동 정보를 탐색하고 주간 루틴을 구성할 수 있도록 돕는 AI 운동 코치 서비스입니다.

기존 운동 정보 서비스는 운동 영상, 설명, 루틴 추천, 부상 회피 정보가 분리되어 있는 경우가 많습니다. 사용자는 운동을 검색한 뒤 다시 난이도, 장비, 부위, 통증 위험을 따져야 하고, 매주 루틴을 직접 조합해야 합니다.

이 프로젝트는 운동 데이터베이스와 AI 상담, 주간 루틴 저장 기능을 하나의 흐름으로 묶어 다음 가치를 제공합니다.

- 운동별 가이드, 주의사항, 대상 근육, 장비, 난이도 제공
- 사용자의 통증 부위와 운동 목적을 고려한 루틴 구성
- AI 챗봇을 통한 운동 관련 질의응답
- 게스트 사용자를 위한 device UUID 기반 상담/루틴 저장
- 운동 목록과 상세 정보를 분리한 성능 최적화

## 문제 정의

### 사용자 문제

- 운동 정보가 흩어져 있어 초보자가 어떤 운동을 선택해야 할지 판단하기 어렵습니다.
- 특정 부위 통증이 있을 때 어떤 운동을 피해야 하는지 알기 어렵습니다.
- 주간 루틴을 직접 설계하려면 운동 부위, 세트, 반복, 장비, 요일 배치를 모두 고려해야 합니다.
- 긴 운동 목록과 무거운 GIF/영상 미디어는 페이지 진입 속도를 떨어뜨립니다.

### 시스템 문제

- 운동 목록 API가 상세 설명, 가이드, 주의사항까지 한 번에 내려주면 초기 응답 크기가 커집니다.
- 홈 화면에서도 전체 운동 데이터를 불러오면 첫 화면 성능이 나빠집니다.
- 카드 목록에서 GIF/MP4를 대량 로드하면 브라우저 디코딩 비용이 커집니다.
- 챗봇과 루틴, 운동 백과가 같은 운동 데이터 소스를 사용하므로 API 필드 설계가 중요합니다.

## 해결 방안

### 서비스 관점

- 운동 백과 페이지에서 카테고리, 장비, 난이도, 검색어 기반으로 운동을 탐색합니다.
- 운동 상세 모달에서 가이드, 시작 자세, 주의사항, 관련 운동을 제공합니다.
- 루틴 페이지에서 통증 부위, 분할 방식, 운동 요일, 목표, 운동 시간을 입력받아 주간 루틴을 생성합니다.
- 상담 페이지에서 AI 챗봇이 운동 관련 질문에 답하고 대화 이력을 저장합니다.

### 기술 관점

- React Router 기반 SPA 라우팅으로 `/exercise`, `/routine`, `/consult` 페이지를 분리했습니다.
- Django API는 운동 목록, 운동 상세, 추천 운동, 상담 세션, 메시지, 루틴 저장 API를 제공합니다.
- PostgreSQL과 pgvector를 사용해 운동 임베딩 기반 검색과 RAG 상담 흐름을 지원합니다.
- 운동 목록 API를 경량 목록 응답과 상세 응답으로 분리했습니다.
- 홈 운동 섹션은 전체 운동 API 대신 추천 8개 API만 호출하도록 최적화했습니다.
- 목록 카드의 기본 미디어는 GIF/MP4 대신 정적 CSS 썸네일로 대체해 초기 렌더링 부담을 줄였습니다.
