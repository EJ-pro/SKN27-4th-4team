## 프로젝트 한 줄 요약

HELBOTIN은 운동 데이터베이스, 주간 루틴 생성, AI 운동 상담을 결합한 개인 맞춤형 운동 코칭 웹 서비스입니다.

## 주요 키워드

- React SPA
- Django API
- PostgreSQL + pgvector
- 운동 백과
- 주간 루틴
- AI 챗봇
- RAG
- Docker Compose
