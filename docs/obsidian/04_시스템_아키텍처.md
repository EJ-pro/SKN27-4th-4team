# 시스템 아키텍처

## 전체 구조

```mermaid
flowchart LR
    User["사용자 브라우저"] --> Frontend["React + Vite Frontend"]
    Frontend --> Backend["Django Backend API"]
    Backend --> DB["PostgreSQL + pgvector"]
    Backend --> OpenAI["OpenAI API"]
    Backend --> RAG["LangGraph RAG Pipeline"]
    RAG --> DB
    RAG --> OpenAI
```

## 주요 컴포넌트

| 컴포넌트 | 역할 |
|---|---|
| Frontend | 화면 렌더링, 라우팅, 사용자 입력 처리 |
| Backend API | 운동 데이터, 상담 세션, 메시지, 루틴 API 제공 |
| PostgreSQL | 사용자, 운동, 상담, 루틴 데이터 저장 |
| pgvector | 운동 임베딩 기반 벡터 검색 |
| LangGraph RAG | 질문 분류, 검색, 답변 생성 흐름 관리 |
| OpenAI | LLM 답변 생성 및 임베딩 생성 |

## 시퀀스 다이어그램

### 운동 목록 조회

```mermaid
sequenceDiagram
    participant U as 사용자
    participant F as Frontend
    participant B as Backend
    participant D as PostgreSQL

    U->>F: /exercise 페이지 진입
    F->>B: GET /api/exercises/
    B->>D: exercises 목록 필드 조회
    D-->>B: 경량 운동 목록
    B-->>F: id, name, category, equipment, difficulty
    F-->>U: 검색/필터/페이지네이션 목록 표시
```

### 운동 상세 조회

```mermaid
sequenceDiagram
    participant U as 사용자
    participant F as Frontend
    participant B as Backend
    participant D as PostgreSQL

    U->>F: 운동 카드 클릭
    F->>U: 목록 데이터로 모달 즉시 표시
    F->>B: GET /api/exercises/{exercise_id}/
    B->>D: 해당 운동 상세 필드 조회
    D-->>B: 상세 정보
    B-->>F: guide, caution, target, related_exercises 등
    F-->>U: 상세 모달 내용 보강
```

### AI 운동 상담

```mermaid
sequenceDiagram
    participant U as 사용자
    participant F as ConsultPage
    participant B as Django Message API
    participant C as Chatbot/RAG
    participant D as PostgreSQL + pgvector
    participant O as OpenAI

    U->>F: 질문 입력
    F->>B: POST /api/sessions/{id}/messages/
    B->>D: 사용자 메시지 저장
    B->>C: stream_answer(question, session_id)
    C->>D: 이전 대화 및 운동 데이터 검색
    C->>O: 질문 분류 및 답변 생성
    O-->>C: 답변 토큰/결과
    C-->>B: 답변 스트림
    B-->>F: SSE token
    B->>D: 봇 메시지 저장
    B-->>F: done 이벤트
    F-->>U: 질문 아래에 답변 표시
```

### 주간 루틴 저장

```mermaid
sequenceDiagram
    participant U as 사용자
    participant F as RoutinePage
    participant B as Routine API
    participant D as PostgreSQL

    U->>F: 통증, 분할, 요일, 목표, 시간 입력
    F->>B: GET /api/exercises/?full=1
    B->>D: 운동 상세 목록 조회
    D-->>B: 운동 데이터
    B-->>F: 전체 운동 데이터
    F->>F: 조건 기반 루틴 생성
    F->>B: POST /api/routines/
    B->>D: weekly_schedulers upsert
    B->>D: daily_routines 재생성
    D-->>B: 저장 완료
    B-->>F: scheduler_id, created
    F-->>U: 루틴 확인 화면 표시
```
