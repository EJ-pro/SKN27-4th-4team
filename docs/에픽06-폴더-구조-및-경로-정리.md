### Step 3 — 루트 `.env` 명시 로드

`cd backend` 로컬 실행 시 CWD 기준 `load_dotenv()`는 **프로젝트 루트 `.env`를 읽지 못한다**.  
Docker는 `env_file: .env`로 주입되므로 영향 없고, **로컬 직접 실행**에 필요하다.

#### 3-1. Django settings

**파일:** [`backend/config/settings.py`](../backend/config/settings.py)

**Before (L1~L8):**

```python
from pathlib import Path
import os
from dotenv import load_dotenv
from datetime import timedelta

load_dotenv()

BASE_DIR = Path(__file__).resolve().parent.parent
```

**After:**

```python
from pathlib import Path
import os
from dotenv import load_dotenv
from datetime import timedelta

BASE_DIR = Path(__file__).resolve().parent.parent
load_dotenv(BASE_DIR.parent / ".env")
```

#### 3-2. recommendation_service config

**파일:** [`backend/recommendation_service/config.py`](../backend/recommendation_service/config.py)

**Before:**

```python
from dataclasses import dataclass
import os

from dotenv import load_dotenv


load_dotenv()
```

**After:**

```python
from dataclasses import dataclass
import os
from pathlib import Path

from dotenv import load_dotenv

_REPO_ROOT = Path(__file__).resolve().parents[2]
load_dotenv(_REPO_ROOT / ".env")
```

#### 3-3. build_graph.py

**파일:** [`backend/db/build_graph.py`](../backend/db/build_graph.py)

**Before (import 직후):**

```python
from dotenv import load_dotenv
from neo4j import GraphDatabase

load_dotenv()

# ── 설정 ────────────────────────────────────────────────────────────────────
BACKEND_DIR = Path(__file__).resolve().parent.parent
```

**After:**

```python
from dotenv import load_dotenv
from neo4j import GraphDatabase

BACKEND_DIR = Path(__file__).resolve().parent.parent
load_dotenv(BACKEND_DIR.parent / ".env")
```

**Step 3 검증:**

```powershell
cd backend
..\.venv\Scripts\python.exe manage.py check
# System check identified no issues
```

> **NEO4J 참고:** `recommendation_service.config.settings`는 **추천 API 호출 시** `_load_recommendation_service()`에서 로드된다. Django `check` 실패는 주로 Step 3 `.env` 미로드 또는 DB env 누락이다. import 시점에 NEO4J가 필수는 **아님**.

### Step 7 — CLI wrapper (선택)

**신규 파일:** [`backend/scripts/run_recommendation_cli.py`](../backend/scripts/run_recommendation_cli.py)

```python
"""
Run recommendation_service CLI from repo root or backend/.

Usage (from repo root):
  python backend/scripts/run_recommendation_cli.py --scenario 0
  python backend/scripts/run_recommendation_cli.py --list-scenarios

Equivalent (from backend/):
  python -m recommendation_service.cli --scenario 0
"""
from __future__ import annotations

import runpy
import sys
from pathlib import Path


def main() -> None:
    backend_dir = Path(__file__).resolve().parents[1]
    if str(backend_dir) not in sys.path:
        sys.path.insert(0, str(backend_dir))
    sys.argv[0] = str(backend_dir / "recommendation_service" / "cli.py")
    runpy.run_module("recommendation_service.cli", run_name="__main__")


if __name__ == "__main__":
    main()
```

**실행 예:**

```powershell
# repo root
.\.venv\Scripts\python.exe backend/scripts/run_recommendation_cli.py --list-scenarios

# backend/
cd backend
..\.venv\Scripts\python.exe -m recommendation_service.cli --list-scenarios
```

**Step 7 검증:** `--list-scenarios` 출력에 시나리오 index 목록 표시.
